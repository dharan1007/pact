# Code of Conduct

PACT is an open security/agent-infrastructure engineering community. Participation is welcome regardless of experience level, background or employer, provided discussion remains technically rigorous and respectful.

## Expected behavior

- Critique claims, threat models, code and evidence rather than people.
- Distinguish demonstrated security properties from assumptions.
- Treat good-faith security review as valuable, even when it challenges project claims.
- Help first-time contributors turn concerns into reproducible cases.
- Protect credentials, personal data and unpublished vulnerability details.
- Disclose conflicts of interest when recommending providers, security products or benchmarks.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized conduct, doxxing, deliberate disruption, spam, public disclosure of unpatched exploit details without coordination, fabricated security evidence, deceptive contribution activity and attempts to manipulate stars/votes/contributor counts are not acceptable.

## Enforcement

Maintainers may edit, hide, reject or remove comments, issues, pull requests or other contributions that violate these expectations and may restrict participation where necessary.

Security-sensitive findings must follow `SECURITY.md`. For conduct concerns, contact the repository owner privately through the maintainer's GitHub profile and avoid reposting private information publicly.
